# 河流声音地图 · 亲子互动装置

孩子沿着一条虚拟河流拖动声波碎片，把它们拼成一段会随水流变化的声音地图；家长调节河流速度与水位，孩子在不同水位下寻找被淹没的音符。

无需登录、无后端、无外部音频资源（全部声音由 Web Audio 实时合成）。

## 玩法

**孩子**
- 把河里漂着的声波碎片（do re mi sol la…）拖进顶部 6 个圆圈，拼出循环播放的河流之歌
- 把碎片从圆圈拖回河里即可取下；拖到已占用的圆圈会交换
- 水位上涨时，河床上的 ♪ 音符被淹没后会发光冒泡，点一下收集；集齐 6 个触发庆祝音阶并刷新一轮

**家长（右上角 🎛️ 面板）**
- 🌊 水流速度：同时影响碎片漂流速度、音序器 BPM、音色亮度和水声大小
- 💧 水位高低：决定哪些音符被淹没、可以被找到
- ☀️ / 🌧️ / 💨 三种天气：晴天波光、雨天涟漪+雨滴声、风天落叶+阵风推碎片（待机 75 秒自动轮换）
- 🎙️ 录一段声音：调用手机麦克风录 4 秒，孩子的声音会变成一块新的橙色碎片游进河里
- 🔴 录下演奏：把孩子拼的旋律录成音频文件保存——**不需要麦克风权限**，直接收录设备内部混音（内置音符、录音碎片与流水/雨/风环境声都在里面）；支持开始、停止、取消，最长 60 秒（到点自动停），停止后可试听、下载到本机（`.webm`，Safari 为 `.m4a`）或放弃重录；录音期间即使点了🔊静音也照常录得到
- 🎧 听音挑战：随时开始/退出；家长播放 3 个固定短旋律关卡，孩子只用内置音符碎片按顺序拼出，支持重听示范、提交答案、位置提示与完成反馈；示范时会暂停当前循环，避免声音重叠
- 📖 声音探索任务册：把音符、录音碎片和天气环境声组织成 5 个亲子引导式创作任务（见下）
- 📚 本地作品集：给孩子的河流之歌起名字保存；之后可随时重新打开、覆盖保存或另存为新歌、删除；单首可导出成备份文件，在另一台设备导入继续编辑
- 🔊 静音开关

## 声音探索任务册（📖）

家长面板里的「📖 任务册」是一本可以盖章的小手册，5 个任务按由易到难排序：

1. **🌦️ 天气小耳朵** —— 听三种天气的水声，说说哪里不一样
2. **🎵 音符碰碰乐** —— 第一次把音符拖进圆圈，感受水流怎样改变歌的速度
3. **💧 潜水找音符** —— 调高水位，收集发光冒泡的水下音符
4. **🎙️ 我的声音游进河** —— 录两段声音，让橙色碎片游进歌里
5. **🏆 我们的河流之歌** —— 编排 ≥4 格、起名字、保存进作品集

每个任务包含两类小步骤：

- **自动**（蓝标签）：孩子做到就自动盖章——切天气、调水位/水流、放碎片、收音符、录音、保存作品都会被感知；卡片内还提供「切到雨天」「帮我调高水位」等快捷按钮，家长一键布置场景
- **盖章**（橙标签）：亲子聊天与表达任务（“你最喜欢哪种天气的声音？”），聊完由家长点前面的圆圈盖章，可反复取消
- **👀 边玩边看**：展开任一未完成任务，点卡片底部的「边玩边看」，任务册收起、河面上留下一条紧凑提示条，实时显示当前第一个未完成步骤、`已完成步数/总步数` 进度和展开按钮；手动步骤可直接在提示条上盖章，快捷动作（切天气/调水位…）也一键可达，孩子操作河流时指引不离开视线。任务盖满章后提示条自动带去下一个任务，整本完成自动消失；提示条与听音挑战互斥（挑战时暂时藏起，退出后回来）

完成一个任务弹一次小鼓励音，整本完成播放庆祝音阶。进度（自动事实 + 手动盖章）只保存在本机 localStorage（键名 `river-taskbook-v1`），无后端；家长可在手册底部两步确认后「清空任务册」重新开始。任务册与听音挑战互斥：挑战进行中不能打开任务册。

## 作品集（本地保存）

家长在面板底部的「📚 河流之歌作品集」里：

- **💾 保存这首歌**：首次保存会弹窗让家长命名（留空则自动取名）；正在编辑某首歌时再点即覆盖保存，也可用「另存为新歌」存成新作品
- **重新打开**：点列表里任意作品，整条河流恢复成保存时的样子
- **📤 导出**：点作品旁的 📤 把这一首存成 `.river-song.json` 备份文件，可经微信 / AirDrop 发到另一台设备
- **📥 导入**：在另一台设备点「导入作品备份」选中该文件，歌就进作品集了（不会自动打开，点一下才恢复河流）；若与本机已有作品重复，会存成新作品、两者都保留
- **删除**：点 🗑️ 后需再点一次确认（3 秒不确认自动取消），防止误删孩子的作品

每首歌完整保存：**6 个格子的顺序与空格、河里所有声音碎片及孩子的录音、水流速度、水位、天气**。
数据只写在这台设备浏览器的 localStorage（键名 `river-songs-v1`），无后端、无登录、不上传；录音以 base64 存储，本地空间不足时会提示家长。导出的备份文件就是单首作品的存档 JSON（含 base64 录音）；导入时做严格校验（版本标识、必需字段、取值范围、格子与碎片的引用必须完整一致），普通 JSON 或残缺、损坏的文件会被明确拒绝，不会被补成空歌收进作品集。

## 技术栈

p5.js（渲染）· TypeScript · Vite · Web Audio API（合成 + 音序器 + 混音内录 + 录音解码）· Matter.js（浮力/漂流/阵风物理）

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 类型检查 + 打包到 dist/
npm run preview  # 预览构建产物
```

## 手机上调试麦克风

`getUserMedia` 要求安全上下文（HTTPS 或 localhost）：

- 电脑本机直接开 `http://localhost:5173` 即可
- 手机访问电脑局域网 IP 是 HTTP，麦克风会被浏览器拒绝。可以：
  - 用 `npx vite --host` 配合隧道（如 `ngrok http 5173`）获得 HTTPS 地址
  - 或部署到任意静态 HTTPS 托管（`npm run build` 后上传 `dist/`）

## 目录结构

```
src/
  main.ts            入口
  Game.ts            编排：物理力、拖拽、格子、音符、存档序列化/恢复、渲染
  audio/AudioEngine  音序器 + 水/雨/风环境声 + 音效（纯合成），mix 总线可引出内录
  audio/MicRecorder  麦克风录音入口（变成河里的声音碎片）
  audio/PerformanceRecorder  录下演奏：从 mix 总线内录完整演奏（MediaStream + MediaRecorder，上限 60 秒）
  data/Portfolio     本地作品集：localStorage 增删改查 + 录音 base64 编解码
  tasks/tasks        声音探索任务册：5 个亲子任务定义、自动事实/手动盖章与 localStorage 进度
  world/Fragment     声波碎片（Matter 刚体 + 波形绘制，带稳定 id）
  world/Notes        被淹没的音符与气泡
  world/Weather      晴/雨/风粒子系统
  ui/Panel           家长面板（HTML 覆盖层，含作品集列表与命名对话框）
  ui/ListeningChallenge  听音挑战控制条与 3 个固定关卡状态
  ui/TaskBook        声音探索任务册覆盖层（任务卡片、盖章、快捷动作、边玩边看紧凑提示条）
```
